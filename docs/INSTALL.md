# 安装与使用

## 安装正式版

从 [Releases](https://github.com/nina-CP200/SoundLock/releases) 下载最新的 `SoundLock-0.1.11-release.apk`，传到手机安装，或在授权 ADB 后执行：

```sh
adb install -r SoundLock-0.1.11-release.apk
```

正式版与调试版签名不同。若手机已安装调试版，通常需要先卸载再安装正式版；卸载会清除应用设置，需重新开启服务和授权。

## 安装开发包

请先按 [README](../README.md) 构建调试包，再将 `app/build/outputs/apk/debug/app-debug.apk` 传到手机安装，或在授权 ADB 后执行：

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

调试签名用于开发，不要与正式版混用。

## 开启保护

1. 打开声锁，点击「开启保护」，阅读用途说明后前往系统无障碍设置。
2. 开启「声锁 · 音量保护」。若系统限制侧载应用的无障碍权限，请在应用信息中检查「允许受限设置」等入口，具体菜单以系统为准。
3. 返回声锁，检查保护状态。首页的「外放保护」开关可暂停或重新开启保护。
4. 在「设置」中按需允许状态通知和精确定时。通知无提示音、无振动；精确定时用于减少息屏自动上锁延迟。
5. 按系统实际提供的选项检查后台活动、自启动等设置。声锁不会自动修改系统优化或权限策略。
6. 可在系统快捷设置中添加「声锁」磁贴。

## 日常操作

锁定时按音量加键，点击顶部提示中的「确认解锁」即可。取消、等待超时或重复按音量键均不会解锁。解锁只恢复最低一格媒体音量，之后可自行调高。

连续 15 分钟无活动媒体播放后自动上锁；播放期间不计时。媒体音量归零、耳机断开和服务重连也会重新上锁。上锁时短暂显示反馈，随后隐藏。

外接设备正常使用，切回手机后重新上锁。顶部提示尚未接入 OPPO 原生流体云。

「关于 → 使用说明」包含详细说明和当前音量诊断；「我要说的话」是作者寄语；「GitHub 项目」在外部应用中打开仓库。

## 首次使用时验证

请先在允许出声的场所检查：

- 实体音量加键的短按、长按、取消、超时与确认解锁。
- 自动上锁后最低档是否仍有声音，以及系统音量面板调高后的归零情况。
- 播放、暂停、15 分钟空闲及息屏休眠后的行为。
- 有线、USB、蓝牙耳机与断开后切回手机的行为。
- 通话、铃声、闹钟和已有读屏服务是否正常。
- 服务关闭、后台清理、设备重启后的保护状态。

普通应用无法承诺绝对零漏音。服务被系统关闭或停止时无法继续保护。
